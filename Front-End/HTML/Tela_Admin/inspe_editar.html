Inspeção da Peça Mouse

  1. Verificar se a cor do mouse é preta.
  2. Verificar se o mouse é USB ou Bluetooth.
  3. Verificar se o peso do mouse está entre 85-90g.
  4. Verificar se o acabamento do plástico é fosco.
  5. Verificar se o clique esquerdo faz som.
  6. Verificar se o botão do scroll clica.
  7. Verificar se o compartimento da pilha fecha bem.
